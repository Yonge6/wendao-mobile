# 问道同行 / Wendao Companion 设计

## 产品定义

问道同行是一位会逐渐理解读者人生脉络的长期反思伙伴。它以《道德经》81章为思想根基，以用户主动产生的对话、实践反馈和可选人生说明书为上下文，帮助读者看见反复出现的主题，并将理解落到一个现实可行的小行动。

它不是通用聊天机器人、命运判断工具、心理咨询替代品，也不以高频通知制造依赖。

## 已确认的产品边界

- AI 使用前必须登录，支持 Apple 与 Google。
- 自动记忆，用户可以查看、修改、暂停、单条删除和全部清除。
- 温和主动：打开产品时的一句相关提醒、实践后的轻度回访、每周一次回顾。
- 人生说明书可选。没有出生资料也能使用 AI；完成说明书后才加入类型、策略、权威与人生角色。
- 现有阅读、搜索、分享与人生说明书继续免费。
- AI 首个正式公开版本即收费，没有试用期或免费问答。
- 月付与年付同时提供，年付为主推方案。
- H5 与 iOS 同时开放，共享账户、记忆、对话和会员权益。
- iOS 使用 StoreKit，H5 使用 Stripe；两种购买来源不能重复扣费。
- 有效会员在订阅期内可无限次提问。自动记忆、章节检索和每周回顾同样不设次数额度。
- 付费层名称为 `问道同行 / Wendao Companion`。
- DeepSeek 为首发模型供应商，但必须通过可替换的服务端适配层调用。

## 用户体验

### 免费阅读

未登录读者继续完整使用现有 81 章阅读、目录、搜索、分享、日夜模式、字号和人生说明书。免费体验不因商业化缩减。

### 进入问道同行

章节底部的安静输入入口和抽屉中的“我的问道”都可以进入问道同行。未登录时先展示价值说明，再进入 Apple/Google 登录；登录但无有效权益时显示月付/年付订阅页；购买成功后立即回到原问题。

### 我的问道

登录且订阅有效时提供四个主要区域：

1. 继续对话：回到最近正在思考的事情。
2. 今日与你有关：结合近期记忆和当天章节给一句提醒。
3. 这一周看见了什么：整理反复主题、变化、相关章节和下一步实践。
4. 关于我的记忆：查看、编辑、暂停、删除或清空长期记忆。

### 回答结构

每次回答依次完成：

1. 用简短语言看见用户此刻的真实矛盾；信息不足时先问一个问题。
2. 从当前章节或最相关的一至三章中引用原句，并区分原文、解释与当代应用。
3. 只引用与问题真正相关的长期记忆；人生说明书只作可选观察角度。
4. 给出一个具体的小实践，说明何时做、观察什么、如何判断是否有帮助。

默认回答安静、诚实、具体、不过长，不堆砌金句，不杜撰老子观点，不替读者做决定。

## 自动记忆

### 记忆类型

- 当前处境：短期事件与正在发生的变化。
- 反复主题：在多次对话中重复出现的模式。
- 偏好边界：用户明确表达的偏好、节奏和界限。
- 实践结果：采用过的行动、结果和反馈。
- 人生说明书：独立保存的计算结果摘要，仅在用户主动创建后使用。

### 生命周期

每条记忆记录来源会话、形成时间、最近使用时间、状态和置信度。短期事件可以过期；已经解决的问题标记为已过去；稳定偏好长期保留。系统不能因为一次表达就生成固定人格或诊断标签。

回答时只检索少量相关记忆，不把全部历史对话发送给模型。删除记忆后立即停止检索，并进入后端删除流程。删除账户时级联删除对话、记忆、周回顾和可选人生说明书。

## 技术架构

### 客户端

继续使用一套 React/Vite 源，同时服务 GitHub Pages H5 和 Capacitor iOS。新增伴侣领域模块、登录会话、权益状态、对话流、记忆管理和付费墙；章节数据仍只有现有一套。

### 身份与数据

使用 Supabase Auth 统一 Apple/Google 登录。Postgres 保存账户资料、会话、消息、长期记忆、每周回顾、人生说明书引用、使用观察和统一权益。所有用户表启用 RLS，策略使用 `(select auth.uid()) = user_id`，并为外键和高频过滤列建索引。

### Wendao API

独立服务端 API 负责：

- 校验 Supabase JWT 与账户状态。
- 校验统一会员权益与剩余额度。
- 装配章节、相关记忆和可选人生说明书上下文。
- 调用模型并流式返回回答。
- 保存消息并异步提炼记忆。
- 接收 Stripe webhook 和 App Store Server Notifications。
- 生成每周回顾、处理数据导出与删除任务。

前端永远不能获得 DeepSeek、Stripe、Supabase service-role 或 Apple 服务端密钥。

### 模型路由

- DeepSeek V4-Pro：用户可见回答、复杂追问、每周回顾。
- DeepSeek V4-Flash：章节候选筛选、记忆提炼、主题分类和结构化输出。
- 统一模型接口允许以后增加其他供应商或故障切换。

发送给模型的身份只使用不可逆的内部匿名标识。账户邮箱、Apple/Google 标识、支付信息、原始出生日期与原始出生地点不得进入模型请求。可选人生说明书只发送类型、策略、权威、人生角色等最小摘要。

## 订阅与权益

### iOS

StoreKit 提供月付和年付。App 支持购买、恢复购买和打开系统订阅管理。服务端接收 App Store Server Notifications 并幂等更新权益。

### H5

Stripe Checkout 提供月付和年付，Customer Portal 管理付款方式与取消。Stripe webhook 幂等更新同一权益表。

### 跨平台

权益以 Wendao 账户为主体，不以设备或支付平台为主体。网页购买后可在 iOS 登录使用，App Store 购买后可在 H5 登录使用。同一账户已有有效订阅时不再展示第二个购买入口。

## 安全与隐私

- 服务端验证每次请求的 JWT、资源所有权、权益和额度。
- 所有输入做长度、枚举和结构校验；错误不返回堆栈或供应商密钥。
- AI API 采用账户级与 IP 级速率限制，并以幂等键避免重复扣额度。
- 支付 webhook 验证签名并保存事件 ID，重复通知不重复变更权益。
- DeepSeek 数据处理与中国境内处理地点在隐私政策和首次 AI 使用前明确披露。
- 用户可以暂停自动记忆、清空记忆、导出数据和删除账户。
- 高风险医疗、心理、法律、财务和人身安全问题进入专门的安全响应路径。

## 失败处理

- AI 失败：不扣额度、不写记忆，允许重试。
- 回答成功但记忆提炼失败：回答正常保存，后台任务重试。
- 支付完成但 webhook 延迟：客户端轮询权益，并提供恢复购买/刷新状态。
- 订阅到期：历史数据保留并可查看，但停止新 AI 问答与主动回顾。
- 模型供应商故障：返回克制的服务状态，不伪造本地回答；适配层允许后续切换备用供应商。

## 质量与商业化验收

正式发布前必须通过：

- 81 章中英文相关性测试。
- 至少覆盖工作、关系、选择、情绪和无人生说明书/有人生说明书的回答评测。
- 记忆准确、过期、删除、暂停和错误归因测试。
- Apple/Google 登录、跨设备同步、Stripe/StoreKit 沙箱购买和恢复测试。
- RLS 越权测试、API 输入与速率限制测试、webhook 重放测试。
- H5、iOS 真机、离线阅读回归和 App Store 隐私材料更新。

Beta 定价已确定为月付 `¥68 / US$19.99`，年付 `¥698 / US$199.99`；其他国家和地区由 Stripe 和 App Store 按美元基准本地化。有效会员问答次数不限，但服务端保留并发、速率和自动化滥用保护，不将它们变成隐藏的月度限额。
