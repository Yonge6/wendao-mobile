# 全篇“本章主旨 / 对我们的启发”内容精修

## 目标

让 81 章的两层内容承担不同职责：`本章主旨`准确说明这一章在讲什么；`对我们的启发`回答这与今天的生活、关系和工作有什么关系。启发不再使用跨章节复用的“辨认现实 / 检视选择 / 落到行动”框架。

## 内容结构

- 每章中英文各保留一段独立主旨，先说核心张力，再说明老子提供的观察角度，不写成口号或章节摘要模板。
- 每章中英文各保留三条编号启发。每条都是独立完整的段落，包含一个明确提醒、一个可识别的现实场景，以及这样做带来的实际价值或避免的代价。
- 三条之间避免同义反复：优先覆盖个人状态、人与人或共同工作、可执行的日常选择三个不同落点，但不固定使用相同标题或句式。
- 不把人类图建议或 `今日一练`复制进启发；主旨、启发、人生说明书和练习继续各司其职。

## 数据与呈现

继续以 `scripts/chapter-inspirations.mjs` 维护双语编辑内容，由既有章节构建脚本生成唯一的 `src/data/chapters.json`，H5 与 iOS 共用。页面仍使用一条一个的 `01 / 02 / 03` 列表，分享海报完整排版三条内容并随长度增长。

## 质量门槛

- 81 章主旨和 243 条中文、243 条英文启发均非重复文本。
- 每条中文启发至少 55 字，英文至少 110 个字符，避免只有抽象概念而没有现实落点。
- 禁止回归旧通用开头和旧四分类模块。
