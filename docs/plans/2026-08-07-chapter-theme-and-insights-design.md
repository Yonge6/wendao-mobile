# 81章“本章主旨”与三条启发改版

## 内容结构

解释层保留逐句今译，但把原来共用模板的“思想”改为“本章主旨 / Chapter theme”。主旨正文使用每章独立的双语编辑内容；第64章围绕“慎终如始”重新说明从萌芽、推进到收尾都要照看条件与节奏。原有“焦虑、关系、选择、行动”四个独立块从81章全部移除，不再渲染，也不留在章节数据中。

“与你有关 / For you”改为一个始终可见的“对我们的启发 / What this teaches us”模块。模块使用有序列表呈现至少三条完整观点，而不是把一段文字视觉上强制换行。其后仍按原规则显示经过验证的“人生说明书”，并保留“今日一练”。第64章的三条内容分别落在临近完成时的风险、完整交付的定义、把收尾重新当作开始三个层面。

## 数据与验证

继续使用 `src/data/chapters.json` 作为 H5 与 iOS 的同一章节数据源。`RelatedItem` 增加可选 `points`，构建脚本同步生成主旨、三条启发和人生说明书；搜索索引覆盖每条观点，分享海报按编号完整输出三条内容。校验器要求81章中英文均为“启发 + 人生说明书”两项结构、每章至少三条观点、主旨与观点完整，并检查双语内容组合不重复。Playwright 重点验证第64章旧四块消失、主旨新文案、三条启发、中英文切换、分享海报及320/390/720px布局，之后执行完整H5、Sites和iOS同源构建。
