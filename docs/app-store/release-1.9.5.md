# Wendao AI 1.9.5 (30)

Follow-up release for the purchase-navigation correction in source commit `057271f`.

From a locked chapter, “Subscribe to Wendao Companion” now opens the membership purchase view with the annual plan selected. “Unlock every chapter forever” opens the same purchase view with the lifetime plan selected. Neither entry opens the AI conversation first.

The production client build, TypeScript check, 166 automated tests and direct Chrome checks for both purchase entries passed before release preparation. The signed archive contains all 81 chapters and source commit `057271f`.

## What is new — English

Tao in Everyday Life now includes illustrated stories for all 81 chapters, with English and Chinese images and matching comic reflections. Explore a different visual style in each chapter, zoom in, and share or save the complete image. This update also improves image sharing and sends locked-chapter purchase choices directly to the selected App Store plan. It refreshes the Buer Within link and adds optional usage statistics in More. Statistics are off by default and can be turned off anytime; chat text and birth details are not included.

## 更新说明 — 简体中文

「生活里的道」现已补齐 81 章中英文漫画，每章采用不同的图片风格，并配有解读画面与故事的文字。可以放大阅读、分享或保存完整长图。
本次还改进了图片分享；锁定章节中的订阅与永久解锁入口会直接进入对应购买方案，不再先打开 AI 对话。另更新「不二见己」入口，并在更多菜单加入可选使用统计。统计默认关闭，可随时停用，不包含对话正文和出生资料。
