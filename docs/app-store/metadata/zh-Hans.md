## 描述

三慢问道是一款安静、可离线使用的《道德经》阅读 App。它以马王堆帛书乙本为主要底本，把文本分为“乙本转写、校读正文、现代解读”三个层次，帮助读者看清原字、缺损、校补与传世版本参照之间的边界。

你可以：

- 完整阅读今本 81 章，目录、搜索、偶遇一章与连续阅读互相贯通；
- 查看带声调拼音、逐句今译、思想结构和章节主题；
- 从焦虑、关系、选择与行动四个生活视角重新理解一章；
- 用低负担的“今日一练”，把阅读变成当下可做的一步；
- 在日间与夜间模式之间切换，并调节适合自己的正文字号；
- 在选择提供出生资料后，获得与章节主题结合的“人生说明书”反思提示。

核心 81 章及阅读界面已随 App 打包，无需登录即可离线阅读。人生说明书、提问与反馈属于自愿使用的联网功能；相关提示用于自我观察，不构成医疗、心理、法律或命运判断。

真实自己，流动人生。向内认识自己，向外如水而行。
