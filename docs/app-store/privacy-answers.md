# App Store 隐私问卷映射

这份记录以 `ios/App/App/PrivacyInfo.xcprivacy` 与正式隐私页为准。任何功能变化都必须先同步三处，再提交新构建。

## 总体回答

- 是否收集数据：是，仅在用户主动使用联网功能或产生必要产品事件时。
- 是否用于追踪：否。
- 是否用于第三方广告：否。
- 是否出售数据：否。
- 是否要求账号：否。

## 数据类型

| App Store 数据类型 | 用途 | 与身份关联 | 追踪 | 产品中的对应信息 |
| --- | --- | --- | --- | --- |
| 姓名 | App 功能、产品个性化 | 是 | 否 | 人生说明书中的称呼 |
| 其他联系信息 | App 功能 | 是 | 否 | 用户反馈时自愿填写的联系方式 |
| 其他用户内容 | App 功能 | 是 | 否 | 用户提交的问题、反馈与生成的回应 |
| 用户 ID | App 功能、分析 | 是 | 否 | 随机客户端标识 |
| 产品交互 | App 功能、分析 | 是 | 否 | 章节和功能使用事件 |
| 其他数据 | App 功能、产品个性化 | 是 | 否 | 出生日期、准确时间、出生地点与人类图摘要 |

## 不收集

- 精确或粗略实时位置；出生地点只作为用户主动输入的人生说明书资料处理。
- 健康、健身、财务、支付、联系人、照片、音频或浏览历史。
- 广告标识符或跨 App / 网站追踪数据。
